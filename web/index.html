Search everything you are allowed to see.

One query goes from this browser to several devices at once. Each device checks the key you present and drops what that key does not reach before it ranks. Hidden records are counted where they live and never sent.

    How it works. Each key is a fresh ed25519 keypair with a signed capability chain. The guest chain grants docs.retrieve:search; the engineer chain also grants docs.retrieve:scope:engineer. Your browser signs one Hello per device; each device's gate verifies the chain, and the docs.retrieve cell on it filters by those abilities before scoring. The before and after counts are what each device reports. Open the network tab: with the guest key, no engineer record is in any frame.
